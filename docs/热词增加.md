# 热词增加

## 实现说明

本项目的热词机制为**识别后文本匹配**，而非 Sherpa-ONNX 内置 hotwords 文件。

- 代码位置：`lib/home_screen.dart`
- 匹配函数：`_formatKeywordRecognitionOutput()`
- 常量表：`_chineseOkKeywordOutputs`、`_koreanOkKeywordOutputs`、`_englishOkKeywordOutputs`、`_japaneseOkKeywordOutputs`
- 匹配规则：识别结果**包含**触发词即输出对应标准化指令；英文匹配不区分大小写
- 优先级：按 Map 插入顺序，先匹配先返回

### 如何新增热词

1. 在 `home_screen.dart` 对应语言的 Map 中添加 `'触发词': 'ok_输出'` 条目
2. 短触发词（如单字「测」「핀」）误触率较高，建议优先添加完整词组
3. 同步更新本文档对应表格
