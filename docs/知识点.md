## 什么是 Sherpa-ONNX（sherpa_onnx）

### 概述

**Sherpa-ONNX**（Flutter 包名 `sherpa_onnx`）是开源项目 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 的 **Flutter/Dart 绑定**，由 [k2-fsa](https://github.com/k2-fsa) 团队维护。

核心定位：**在本地设备上运行语音 AI 推理**，不依赖云端 API。

底层使用 **ONNX Runtime** 加载 `.onnx` 模型文件，在手机上直接完成语音识别（ASR）、语音活动检测（VAD）等任务。

| 特点 | 说明 |
|------|------|
| 完全离线 | 模型下载后本地推理 |
| 跨平台 | Android、Windows、macOS、Linux 等 |
| 模型丰富 | 支持多种开源 ASR 模型 |
| 体积可控 | 支持 INT8 量化模型，适合移动端 |

官方仓库：[https://github.com/k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)

### 在本项目中的角色

项目依赖：`sherpa_onnx: ^1.13.0`

| 组件 | Sherpa-ONNX 提供的 API | 用途 |
|------|------------------------|------|
| **SenseVoice** | `OfflineRecognizer` + `OfflineSenseVoiceModelConfig` | 中/英/日/韩识别 |
| **Silero VAD** | `VoiceActivityDetector` | 检测说话起止、切分语段 |

> 当前版本**仅集成 SenseVoice**，不包含 Whisper 等其他引擎。

### 工作原理

```
麦克风 PCM 音频（16 kHz）
        ↓
Silero VAD（sherpa_onnx）→ 切出有效语段
        ↓
OfflineRecognizer（sherpa_onnx）→ 每段解码成文字
        ↓
热词匹配（应用层）→ 标准化指令输出
        ↓
界面显示识别结果
```

项目中的调用流程：

1. `initBindings()` — 初始化 native 绑定
2. `_rebuildVad()` — 创建 `VoiceActivityDetector`
3. `_recognizer = OfflineRecognizer(...)` — 加载 SenseVoice，传入当前 `langCode`
4. `_processSegment()` — 每段音频送入识别器解码
5. `_formatKeywordRecognitionOutput()` — 热词后处理

### 使用的模型

| 模型 | 来源 | 大小 | 在本项目中的角色 |
|------|------|------|------------------|
| SenseVoice INT8 | GitHub Releases | ~157 MB | 多语言主模型 |
| Silero VAD | GitHub Releases | ~2 MB | 语音切句 |

模型存储路径：`{应用文档目录}/sherpa_models/`

### 优势与局限

| 优势 | 说明 |
|------|------|
| 离线隐私 | 语音不上传服务器 |
| 模型选择灵活 | 同一套 API 可切换多种 ASR 模型 |
| 移动端优化 | INT8 量化，内存占用相对可控 |
| 与 VAD 集成 | 内置 Silero VAD，适合「长按说话、分段识别」 |
| Flutter 官方绑定 | 通过 `sherpa_onnx` 包直接调用，无需自己写 JNI |

| 局限 | 说明 |
|------|------|
| APK 体积 | native `.so` 库较大 |
| 离线识别模式 | 使用 `OfflineRecognizer`，按 VAD 段出字，非流式逐字 |
| 模型需预下载 | 首次使用需从 GitHub 下载模型（国内可能较慢） |
| 大模型限制 | 更大模型在现有架构下可能 OOM（见 [手机压力测试.md](./手机压力测试.md)） |

## UI 国际化（AppStrings）

本项目未使用 `flutter_localizations`，而是通过自建组件实现四语言界面：

| 组件 | 作用 |
|------|------|
| `AppUiLanguage` | 枚举：zh / en / ja / ko |
| `AppStrings` | 按当前 UI 语言返回文案 |
| `AppLocaleScope` | InheritedWidget，子树读取文案与切换语言 |

**注意**：UI 语言与识别语言相互独立。例如界面为韩语，识别语言仍可选中文。
