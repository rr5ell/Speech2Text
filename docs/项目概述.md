# 项目概述

## 项目简介

**Speech_to_Text**（Dart 包名 `speech_to_text_sherpa`，Android 包名 `com.vosk.stt.speech_to_text_vosk`）是一款基于 Flutter 的**离线语音转文字**应用。支持中文、英文、日语、韩语识别，无需联网即可完成推理（首次使用需下载模型）。

当前版本：`2.0.0+1`

---

## 核心能力

| 能力 | 说明 |
|------|------|
| 多语言识别 | 中文 / English / 日本語 / 한국어（按所选 `langCode` 传入 SenseVoice） |
| 多语言界面 | 中 / 英 / 日 / 韩 UI 文案，AppBar 可切换 |
| 统一引擎 | 全语言共用 SenseVoice INT8 + Silero VAD |
| 完全离线 | 模型下载后本地推理，无云端 API 依赖 |
| 长按说话 | 150 ms 长按开始录音，松手结束 |
| 引擎预热 | 模型就绪后后台预加载，降低首次录音延迟 |
| 热词后处理 | 识别文本匹配触发词后输出标准化指令（见 [热词增加.md](./热词增加.md)） |
| 识别历史 | 本地 JSON 持久化，最多 100 条，支持复制、清除与单条删除 |

## 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | Flutter（Dart SDK ^3.5.0） |
| UI | Material 3，支持浅色/深色主题 |
| Sherpa 识别 | `sherpa_onnx` — SenseVoice INT8 |
| 语音活动检测 | Silero VAD（`silero_vad.onnx`） |
| 音频采集 | `record` — 16 kHz 单声道 PCM 流式录音 |
| 权限 | `permission_handler` — 麦克风权限 |
| 模型下载 | `dio` + `archive`（tar.bz2 解压，Isolate 中解压） |
| 本地存储 | `path_provider` + JSON 文件 |
| 国际化 | `AppStrings` + `AppLocaleScope`（自建，非 flutter_localizations） |

## 识别引擎架构

```
                         ┌─────────────────────────────────┐
                         │         HomeScreen              │
                         │  识别语言 / 录音 / 热词 / 历史   │
                         └───────────────┬─────────────────┘
                                         │
                                         ▼
                              Sherpa-ONNX SenseVoice
                              + Silero VAD 分段识别
                                         │
                                         ▼
                              热词匹配 → 标准化输出
```

当前版本**仅使用 SenseVoice 单引擎**，不再包含 Whisper 等其他 ASR 路线。

## 核心识别流程

1. **模型就绪检查** — 检测 VAD + SenseVoice 是否已下载。
2. **引擎预热** — 加载 Silero VAD 与 `OfflineRecognizer`；韩语场景使用更宽松的 VAD 参数。
3. **流式录音** — 16 kHz PCM，512 样本窗口送入 VAD。
4. **语音分段** — VAD 检出有效语段，每段独立解码。
5. **文本过滤** — 去除标点；韩语模式额外过滤非韩文字符。
6. **热词匹配** — 按识别语言查表，命中触发词则输出对应 `ok_*` 指令。
7. **结果展示** — 追加识别文本；松手时 `vad.flush()` 处理剩余片段并写入历史。

## 模型与下载

| 模型 | 来源 | 格式 | 约计大小 | 使用场景 |
|------|------|------|----------|----------|
| SenseVoice INT8 | GitHub Releases | `.tar.bz2` | ~155 MB | 中/英/日/韩 |
| Silero VAD | GitHub Releases | 单文件 `.onnx` | ~2 MB | 全语言 VAD 切句 |

- 模型目录名含 `yue`（粤语），但当前 UI 未单独暴露粤语选项。
- 模型按需下载，已下载的不重复拉取。
- 下载地址定义于 `model_manager.dart`。

## 特点摘要

- **单引擎架构**：Sherpa-ONNX SenseVoice 覆盖全部识别语言
- **按需下载**，安装包体积较小，模型分离存储
- **VAD 分段识别**，适配长按说话场景
- **引擎预热 + 150 ms 长按**，交互响应快
- **四语言 UI** 与 **领域热词**，面向多语言现场指令场景
- **识别历史** 本地保存，支持复制与清除
