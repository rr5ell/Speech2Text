# 关于是否可以商用

本文档说明本项目中使用的语音模型（SenseVoice、Silero VAD 等）的**商用许可**、**上架应用商店注意事项**，以及**推荐使用方式**。

> **免责声明**：本文档为项目开发者的整理说明，不构成法律意见。正式商业发布前，建议阅读各组件的原始许可全文，必要时咨询法务。

## 二、能不能商用？

### 简短结论

**可以商用，也可以上架应用商店**，但需要同时满足：

1. **模型许可**（FunASR Model License 等）
2. **开源组件合规**（Apache 2.0 等）
3. **应用商店审核规则**（隐私政策、权限说明、下载体验等）

「能从 GitHub 下载」≠「可以随便用」，必须完成合规声明。

模型许可主要要求：

- 使用时须 **标注来源和作者信息**

- 不得恶意诋毁 FunASR 软件（违反可导致授权终止）
- 许可协议可能更新，需关注官方仓库

> 注意：许可文本中有「仅供参考和学习使用」等免责声明，与官方 Issue 中「允许商用」的口径并存。若做正式商业产品，可向 FunAudioLLM / 阿里 FunASR 发 Issue 或邮件索取书面确认（参考 [Issue #279](https://github.com/FunAudioLLM/SenseVoice/issues/279)）。

## 四、能不能上架应用商店？

### 总体答案

**通常可以。** 应用商店审核主要看「你的 App 是否合规」，而不是「模型 URL 是不是 GitHub」。

已有社区案例基于 sherpa-onnx + SenseVoice 发布移动端 App（如 Sherpa-ONNX 文档中提到的 BreezeAPP 等），说明这条技术路线本身可行。

### Google Play / 海外商店

- 首次启动从外网下载 ~155 MB 模型：**允许**
- 建议：
  - 隐私政策中说明「会从网络下载语音模型」
  - 下载失败时有明确提示
  - 商店描述写清楚：**离线识别、语音不上传云端**
  - 麦克风权限用途说明清晰

### 国内应用商店（华为、小米、OPPO、vivo 等）

- 关注 **隐私合规、权限说明、第三方 SDK/模型说明**
- 对 **运行时下载大文件、外链域名** 可能较敏感
- 建议准备 **国内可访问镜像**（自建 CDN、对象存储），不要只依赖 GitHub
- 若 App 收费或含内购，可能还需软件著作权等资质（各地要求不同）

### Apple App Store

- 运行时下载模型 **允许**
- 需说明麦克风用途
- 建议优化首次下载体验

## 五、需要注意的风险点

| 风险 | 说明 | 建议 |
| --- | --- | --- |
| 许可 attribution 缺失 | 未注明 SenseVoice / FunASR / Sherpa-ONNX 来源 | App 内增加「开源许可」页面 |
| 商标误导 | 用户误以为 App 是阿里巴巴官方产品 | 描述写「Powered by SenseVoice / Sherpa-ONNX」，注明非官方 |
| GitHub 下载不稳定 | 国内用户首次打开下载失败或极慢 | 生产环境改用 OSS/CDN 镜像 |
| 动态下载未告知 | 审核或用户投诉 | 隐私政策、关于页说明模型下载行为 |
| 许可灰色表述 | Model License 含「学习用途」免责声明 | 重大商业决策前向官方确认 |

## 六、推荐怎么用（最佳实践）

### 1. App 内增加「关于 / 开源许可」页

建议至少包含：

```
本应用使用以下开源组件：

· Sherpa-ONNX (Apache 2.0) — https://github.com/k2-fsa/sherpa-onnx
· SenseVoice 语音识别模型 (FunASR Model License) — https://github.com/FunAudioLLM/SenseVoice
· Silero VAD

SenseVoice 模型由阿里巴巴 FunAudioLLM 团队发布，经 Sherpa-ONNX 转换为 ONNX 格式。
本应用与阿里巴巴无官方关联。
```

> 当前版本尚未内置该页面，上架前建议补充。

### 2. 模型分发方式

| 方式 | 优点 | 缺点 |
| --- | --- | --- |
| **按需下载**（当前方案） | APK 体积小 | 首次需联网，GitHub 国内可能慢 |
| **打包进 APK** | 开箱即用 | APK 增大 ~155 MB |
| **自建 CDN 镜像** | 稳定、可控 | 需维护存储与带宽 |

**生产环境建议**：将模型文件放到自己的 OSS/CDN，修改 `model_manager.dart` 中的 `_senseVoiceUrl`，并在关于页注明模型来源。

### 3. 隐私政策要点

- 语音在 **设备本地** 处理，不上传服务器
- 首次使用需 **联网下载** 语音模型（约 155 MB）
- 麦克风权限仅用于 **语音识别**
- 识别历史保存在 **本地**

### 4. 商店描述建议措辞

- ✅ 「离线语音转文字，支持中文、英语、日语、韩语」
- ✅ 「Powered by SenseVoice & Sherpa-ONNX」
- ❌ 「阿里巴巴官方语音识别 App」
- ❌ 未说明麦克风用途、未提供隐私政策链接

## 七、常见问题

### Q：用这个 GitHub 链接下载，能上架吗？

**可以**，但需满足第三节许可要求和第四节商店规则，并完成 attribution 与隐私合规。

### Q：模型能否用于付费 App？

**一般可以**。FunAudioLLM 官方确认本地离线商用场景允许，但不能单独转售模型。

### Q：商店会因为从 GitHub 下载而拒审吗？

**通常不会**。需做好隐私说明、权限说明和下载失败处理。国内商店建议用国内镜像。

### Q：和阿里云付费 API 有什么区别？

| | 本项目（SenseVoice ONNX） | 阿里云语音 API |
| --- | --- | --- |
| 费用 | 免费（遵守开源许可） | 按量付费 |
| 网络 | 完全离线 | 需联网 |
| 隐私 | 数据不出设备 | 音频上传云端 |
| 许可 | FunASR Model License | 阿里云服务协议 |

### Q：还需要做什么才能安心上架？

1. 阅读 [FunASR MODEL_LICENSE](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE) 全文
2. App 内添加开源许可页
3. 编写并链接隐私政策
4. 生产环境使用稳定 CDN 替代 GitHub 直链
5. 重大商业发布前向 FunAudioLLM 确认书面许可（可选但稳妥）
